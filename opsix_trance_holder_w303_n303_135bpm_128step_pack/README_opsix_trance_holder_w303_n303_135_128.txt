opsix trance-holder MIDI pack - 135 BPM - 128 steps
No drums in this pack. It is intended for Korg opsix parts around MC-707 drums and a TD-3/303-style acid bass.
Influence target: Crystal Distortion, Drop Bass Network, Network 23, Spiral/free-party energy. Original MIDI material, not copied from tracks.

Naming logic:
- W303 = designed to run while the TD-3/303 is active. These are drones, pads, alarms, bleeps, stabs and textures.
- N303 = designed for moments where the TD-3/303 is muted; opsix temporarily holds the low/bass/trance pressure.
- All separated files are MIDI format 0, one track, 480 PPQ, 8 bars / 128 sixteenth-note steps.
- The all-tracks reference is MIDI format 1 with all 36 parts together; use only as an audition/reference file.

MC-707 workflow note:
File names are intentionally compact enough to identify role and suggested opsix patch. Import one or a few parts, not all 36 at once.
Keep W303 parts sparse under the acid line. Use N303 bass/lowseq clips when you cut the TD-3 for a cyber/digital break.
