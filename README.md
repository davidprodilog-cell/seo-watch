# seo-watch

Liste centralisée des sites à surveiller pour la veille SEO (Cursor Automation).

## Ajouter un site

Édite `sites.yaml` :

```yaml
  - name: "Nom affiché"
    url: "https://ton-site.fr"
    sitemap: "/sitemap_index.xml"
```

## Search Console

Pour chaque site : Search Console → Paramètres → Préférences e-mail → activer les alertes.
